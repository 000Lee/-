# 뇌 병변 부위별 특징 정리 (요양병원 물리치료사용)

> 차트에서 질환명·병변 부위를 보고 환자를 빠르게 파악하기 위한 정리.
> 형식: **한국어 / 영어 / 의학용어** 순, 좌(Lt)·우(Rt) 구분 포함, 물리치료 관점 요약.

---

## 1. 중대뇌동맥 / Middle Cerebral Artery / MCA 경색

가장 흔한 뇌졸중 유형. 운동피질의 상지·안면 영역을 주로 담당.

**공통 특징**
- 반대측 편마비 (얼굴·팔 > 다리)
- 반대측 감각저하 (마비와 같은 분포)
- 반대측 동측성 반맹 (homonymous hemianopia)
- 머리·눈이 병변 쪽으로 편위 (gaze deviation)

**좌측(Lt) MCA → 우측 편마비**
- 실어증 (aphasia): 브로카(운동성)·베르니케(감각성)
- 실행증 (apraxia): 지시 이해해도 동작 수행 안 됨
- 우측 상지·안면 우세 마비
- 병식은 대체로 유지 → 우울·좌절감 동반 많음

> **PT 관점:** 언어 지시가 안 통할 때가 많음. 시범·손동작 유도(비언어적 큐) 중요. 실행증 있으면 말보다 직접 동작 유도.

**우측(Rt) MCA → 좌측 편마비**
- 편측무시 (neglect): 왼쪽 공간·자기 몸 왼쪽 인지 못 함
- 병식결여 (anosognosia): 마비를 부정·과소평가
- 충동성·안전판단 저하
- 좌측 상지·안면 우세 마비

> **PT 관점:** neglect + 병식결여 조합으로 **낙상·안전사고 위험 최다**. 자기 능력 과대평가해 혼자 일어나다 넘어짐. 왼쪽에서 자극·인지 유도 핵심.

---

## 2. 전대뇌동맥 / Anterior Cerebral Artery / ACA 경색

MCA보다 드묾. 운동피질의 하지 영역(내측면) 담당.

**공통 특징**
- 반대측 편마비 (**다리 > 팔·얼굴**) — MCA와 정반대 양상
- 반대측 하지 감각저하
- 요실금 (urinary incontinence)
- 무의욕·무동증 (abulia), 반응 느림
- 전두엽 침범 시 성격변화, 원시반사(파악반사 등)

**좌측(Lt) ACA → 우측 편마비**
- 초피질성 운동실어증 가능
- 우측 하지 우세 마비

**우측(Rt) ACA → 좌측 편마비**
- 좌측 하지 우세 마비
- 무시 증상은 MCA보다 경미

> **PT 관점:** **하지 마비가 주**라 보행·기립 훈련이 핵심 과제. abulia로 동기부여가 안 되는 경우 많아 훈련 참여 유도가 관건. 요실금 동반 시 케어 연계.

---

## 3. 후대뇌동맥 / Posterior Cerebral Artery / PCA 경색

후두엽(시각피질)·시상 일부 담당. 운동마비는 대체로 경미.

**공통 특징**
- 반대측 동측성 반맹 (homonymous hemianopia) — 대표 증상
- 시각 인지장애: 실인증(visual agnosia), 색각장애
- 시상 침범 시 감각저하, 시상통증 (thalamic pain)
- 운동마비는 없거나 경미

**좌측(Lt) PCA**
- 실독증 (alexia), 색이름대기장애
- 우측 시야결손

**우측(Rt) PCA**
- 좌측 시야결손·시각 무시
- 지형 지남력 장애 (길 찾기 어려움)

> **PT 관점:** 마비보다 **시야결손 대응**이 핵심. 반맹 쪽 장애물 미인지로 낙상·부딪힘 위험. 안전한 쪽에서 접근, 시야보상훈련(scanning) 병행.

---

## 4. 뇌교(교뇌) / Pons / Pontine 경색

뇌간(brainstem). 운동·감각로가 밀집해 작은 병변도 증상 큼. 뇌신경핵 위치.

**주요 특징**
- 교차성 마비 가능: 병변측 얼굴 + 반대측 몸
- 구음장애 (dysarthria), 연하곤란 (dysphagia)
- 복시 (diplopia), 안구운동장애
- 현훈 (vertigo), 실조 (ataxia)
- 중증 시 사지마비 + 의식 유지되는 감금증후군 (locked-in syndrome)

> **PT 관점:** **연하·호흡·구음** 문제 동반 잦아 흡인성 폐렴 위험 주의. 균형·실조 훈련 중요. 뇌간 병변은 회복이 느리고 예후 편차 큼. 자세·체위변경 세심하게.

---

## 5. 소뇌 / Cerebellum / Cerebellar 경색

균형·협응 담당. 마비(위약)는 없지만 조절 장애가 특징.

**주요 특징**
- **동측(같은 쪽)** 실조 (ataxia) — 대뇌와 달리 병변과 같은 쪽
- 균형장애, 넓은 보폭 보행 (wide-based gait)
- 측정이상 (dysmetria), 반복운동장애 (dysdiadochokinesia)
- 의도진전 (intention tremor)
- 안진 (nystagmus), 현훈, 구음장애
- 부종 시 뇌간 압박·수두증 위험 (급성기 응급)

> **PT 관점:** 근력은 있으나 **협응·균형 훈련**이 핵심. 체간 안정성, 무게중심 이동, 보행 안정화. 낙상 위험 높음. 진전으로 정밀동작 어려움.

---

## 6. 시상 / Thalamus / Thalamic 경색

감각 중계핵. 감각증상이 주.

**주요 특징**
- 반대측 감각저하 (모든 감각 양식)
- 시상통증 (thalamic pain, Déjérine-Roussy 증후군): 마비 회복 후 나타나는 극심한 이상통증
- 경미한 반대측 위약
- 인지·기억장애, 의식저하 가능
- 눈 아래방향 편위 등 안구운동 이상

> **PT 관점:** 감각저하로 **위치·안전 인지 저하** → 관절보호·낙상주의. 시상통증 있으면 접촉·운동 시 통증 호소, 강도 조절 필요. 감각재교육 접근.

---

## 7. 열공경색 / Lacunar Infarction / Lacune

작은 관통동맥 폐색. 고혈압·당뇨 관련. 순수 증상 패턴이 특징(피질 증상 없음 = 실어증·무시 없음).

**대표 임상형**
- 순수운동 편마비 (pure motor): 얼굴·팔·다리 균등 마비, 감각·언어 정상
- 순수감각 (pure sensory): 반대측 감각저하만
- 실조성 편마비 (ataxic hemiparesis): 위약 + 같은 쪽 실조
- 구음장애-서투른손 (dysarthria-clumsy hand)

> **PT 관점:** 피질증상(인지·언어·무시)이 없어 **재활 협조도가 상대적으로 좋음**. 예후 양호한 편이나 재발·다발성 시 혈관성 인지저하·보행장애 누적 주의.

---
## 8. 뇌실주위 백질 / Periventricular White Matter / PVWM 경색

대뇌피질 아래, 뇌실 주변을 둘러싼 깊은 백질 부위. 주로 고혈압, 당뇨, 노화 등으로 인한 미세혈관 손상(소혈관 질환)이 누적되어 발생함.

**공통 특징**
- 운동 및 감각 신경로(방사관, 피질척수로 등)가 밀집되어 통과하는 구간
- 다발성, 양측성 병변(백질연화증, leukoaraiosis)으로 나타나는 경우가 흔함
- 서서히 진행되는 양상 (급성 편마비보다는 만성적인 악화)

**주요 임상 양상**
- **보행 장애:** 보폭이 짧고 발을 질질 끄는 양상(shuffling gait), 시작 주저함(start hesitation). 혈관성 파킨슨증후군(Vascular Parkinsonism) 형태로 자주 발현
- **경직 및 편마비:** 하지 위주의 양측성 경직(spasticity) 또는 편마비
- **인지 저하:** 실행 기능 저하, 정보 처리 속도 감소를 동반한 혈관성 인지 장애 (피질성 치매와 달리 기억력 감퇴보다는 판단/수행 능력 저하가 두드러짐)
- **자율신경계 이상:** 절박뇨, 요실금 빈발

> **PT 관점:** 특정 부위의 완전 마비보다는 **전반적인 강직(spasticity)과 보행 패턴의 변형**이 주된 문제. 파킨슨 환자와 유사하게 굳은 자세와 짧은 보폭을 보이므로, **낙상 위험이 매우 높음**. 관절 가동범위 유지 및 비정상적인 보행 패턴 교정(보폭 늘리기, 체중 이동 훈련)에 집중해야 하며, 인지 저하와 요실금 동반을 고려한 환경 설정이 필수적.
---

## 부위별 마비 양상 빠른 비교

| 부위 | 마비 우세 | 특징적 증상 | 마비 방향 |
|------|-----------|-------------|-----------|
| MCA | 팔·얼굴 > 다리 | 실어증(좌)/무시(우) | 반대측 |
| ACA | 다리 > 팔 | 요실금, 무의욕 | 반대측 |
| PCA | 없음/경미 | 반맹, 시각장애 | (시야)반대측 |
| Pons | 사지·교차성 | 연하·구음장애, 복시 | 다양 |
| 소뇌 | 없음(실조) | 균형·협응장애 | **동측** |
| 시상 | 경미 | 감각저하, 시상통증 | 반대측 |
| 열공 | 균등 | 순수운동/감각 | 반대측 |
